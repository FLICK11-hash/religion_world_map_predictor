# Previous graduate assignment

These two programs come from the October 2026 graduate course exercise that this project began as.
The exercise asked for the same forecast, the world's religious composition in 2100, 2500 and 3026,
to be built three ways: written by hand, generated by prompting an AI coding assistant, and written
jointly with one. The generated version grew into the research model at the root of this
repository. The other two are kept here, unchanged in substance, as a record of that exercise and
as simple reference forecasts.

Neither is part of the research model, neither is used by it, and neither is a forecast to cite.
Both use only the Python standard library.

| | `manual_predictor/` | `mixed_predictor/` |
|---|---|---|
| Written | by hand | jointly with an AI coding assistant |
| Forecasts | the world composition, 7 groups | the world composition, 8 groups |
| Data | 7 snapshots from non-primary sources | World Religion Project, balanced panel of 131 countries, 1970-2010 |
| Method | linear trend on shares, negatives clipped to zero | damped linear trend on log-shares |
| Validation | none | nested forward-chaining against persistence and four alternatives |
| Tests | none | 17 property checks, 5 methodology checks |

```bash
python previous_grad_assignment/manual_predictor/main.py
python previous_grad_assignment/mixed_predictor/main.py              # forecast with its evidence
python previous_grad_assignment/mixed_predictor/main.py selftest     # 17 checks
python previous_grad_assignment/mixed_predictor/main.py methodology  # the leakage audit below
```

## What the exercise showed

**A trend fitted to world shares cannot be distinguished from assuming nothing changes.** Under a
leakage-free evaluation the mixed predictor's damped trend beats persistence in 2 of 4 folds
(2.962 against 2.977 percentage points, exact paired test p = 1.0). With four folds no two-sided
test can return p below 0.125, so no conclusion stronger than "indistinguishable" is available
from nine global observations.

**Its first evaluation leaked.** The original cross-validation chose the half-life on folds that
included later cuts, and those later cuts are scored on the held-out fold's own target years:
14 of 15 test targets entered the tuning objective. It reported a 9% advantage over persistence
that disappears once the tuning uses the past only. Both procedures are kept in
`mixed_predictor/validate.py` (`cross_validated_comparison`, the original, and
`nested_forward_comparison`, the correction), and `main.py methodology` demonstrates the leak by
altering only post-cut data and showing that the original procedure's choice moves.

**The hand-written version's data were the main problem.** Its 1900-1990 rows came from a search
engine's AI-generated overview and are internally inconsistent. Its averaging method, given the
mixed predictor's data, scores 2.544 pp against 2.977 for persistence, no worse than the more
elaborate trend models.

## Why these errors cannot be compared with the research model's

Both predictors forecast one world composition. The research model forecasts 200 countries and
scores each before aggregating. Aggregation cancels errors: a model that overstates the Muslim
share in one country and understates it by the same number of people in another has zero world
error and positive country error. The mixed predictor's panel also excludes 10.7% of the world's
2010 population, dominated by Indonesia (missing from the World Religion Project files for 1980
and 1985) and Bangladesh, so it does not even describe the same population. A lower world-level
error from these programs says nothing about which approach forecasts better. The only comparison
that survives the difference in design is each model against its own persistence baseline, and on
that measure the exercise and the research model reach the same conclusion.
